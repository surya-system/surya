# 🚀 KREATIKA STUDIO - UI/UX & Web Engineering Agency Website

Company profile multi-halaman berstandar enterprise untuk agensi digital spesialis **Riset UI/UX**, **Desain Antarmuka (Figma)**, dan **Rekayasa Web Modern (React / Next.js / Full-Stack)**.

---

## 🌟 Keunggulan & Fitur Utama

1. **Multi-Page Architecture (8 Halaman Lengkap & Terhubung)**:
   - `index.html`: Beranda utama dengan Hero Section sinematik, statistik animasi counter, showcase studi kasus, kalkulator biaya interaktif, alur kerja, testimoni klien, dan logo marquee tak terbatas.
   - `about.html`: Profil perusahaan, kisah perjalanan (story), visi & misi, 4 nilai utama, tim kepemimpinan (leadership team), serta milestone penghargaan.
   - `services.html`: Rincian 6 layanan utama (UI/UX, Web App, Company Profile, E-Commerce, Design System, Redesign Audit) lengkap dengan daftar deliverables dan tabel perbandingan.
   - `portfolio.html`: Katalog 8+ proyek studi kasus dengan filter kategori instan (*All, Web App, E-Commerce, Company Profile, Fintech*) dan **Pop-up Modal Studi Kasus Interaktif**.
   - `pricing.html`: Paket harga transparan (Starter, Pro, Enterprise) + **Kalkulator Biaya Proyek Real-Time** yang menghitung biaya dan estimasi waktu kerja secara dinamis, serta tombol kirim ke WhatsApp.
   - `process.html`: Framework kerja 5 fase (Discovery, Architecture, Visual UI, Clean Code, QA & Handover) dengan jaminan SLA dan tools yang digunakan.
   - `blog.html`: 6 artikel mendalam seputar psikologi UX, Next.js vs WordPress, design system Figma, dan tren UI 2025 dengan modal pembaca artikel langsung.
   - `contact.html`: Formulir pengajuan proyek interaktif dengan validasi, pembuatan ID tiket unik (`#KTK-XXXXXX`), penyimpanan di `localStorage`, direct WhatsApp chat, dan peta studio.

2. **Desain Visual Kelas Dunia (Awwwards / Enterprise Standard)**:
   - Palet warna Dark Mode futuristik (`#07090E`) dengan aksen gradien neon indigo, violet, cyan, dan emerald.
   - **Dark / Light Mode Switcher** dengan penyimpanan otomatis di `localStorage`.
   - Efek Glassmorphism halus, glowing radial blur, hover card micro-interactions, dan tipografi Google Fonts (*Plus Jakarta Sans* & *Space Grotesk*).
   - 100% Responsif di semua resolusi (Mobile, Tablet, Laptop, Ultra-wide Desktop).

3. **Interaktivitas JavaScript Tanpa Ketergantungan Berat**:
   - Berjalan langsung di browser apa pun tanpa perlu proses instalasi atau build `npm` yang rumit.
   - Cukup klik dua kali `index.html` di File Explorer, atau jalankan melalui Live Server.
